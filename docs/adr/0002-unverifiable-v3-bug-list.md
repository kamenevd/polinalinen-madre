# ADR-0002: Unverifiable v3 bug list

- **Status:** Accepted
- **Date:** 2026-07-25

## Context

Код v4 упоминает баги v3 №1, №3, №6 и №7. Исходный реестр с пунктами №2, №4
и №5 отсутствует во всех ветках и истории репозитория. Найденные старые списки
имеют другую нумерацию и противоречат этим ссылкам.

## Decision

Пункты v3 №2/4/5 закрываются как **historical source unavailable**. Их
содержание не восстанавливается предположениями. Известные fix/hotfix-коммиты
проверяются по фактическому содержанию без присвоения потерянных номеров.

## Consequences

- У автономного агента больше нет вечной невыполнимой задачи.
- Если оригинальный реестр найдётся, создаётся новый ADR и отдельные regression tests.
- Отсутствие источника не трактуется как подтверждение отсутствия багов.
