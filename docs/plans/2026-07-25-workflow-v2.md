# Madre Autonomous Workflow v2 — Implementation Plan

> **For Hermes:** Use subagent-driven-development and strict TDD task-by-task.

**Goal:** Replace the narrative-only development loop with a resumable, fail-closed, evidence-backed state machine that drives planning, implementation, independent review, Android validation, PR merge, and reproducible release.

**Architecture:** A zero-dependency Python control plane stores the current cycle in JSON-compatible YAML, validates ordered transitions and evidence, and prepares release manifests. GitHub Actions enforce the same contracts. Android feature work remains Kotlin/Compose and always occurs on `cycle/N` branches. OpenRouter image generation is optional per feature but, when used, records model and prompt provenance.

**Tech stack:** Python 3 stdlib, unittest, JSON/YAML-compatible state, GitHub Actions, Gradle/AGP 8.2, Kotlin 1.9.20, Android emulator, OpenRouter multimodal API.
