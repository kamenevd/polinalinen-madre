# Дневник: читаемые советы из руководства

## Зачем
Утверждённый пункт SCREENS-7.0.3 §3:104: читать советы отдельными абзацами, не сплошной полосой.

## Что меняем
7.1.20 (73): существующий PaperCard содержит три абзаца — предложения 1+2 / 3 / 4+5. Заголовок «Советы из руководства» остаётся снаружи. Сохраняются PaperType.body, 13sp/19sp, ink2, исходные слова, числа, пунктуация и порядок. Между абзацами 12dp.

## Готово, когда
- На Журнале советов нет; на Советах ровно три текстовых абзаца в одном существующем PaperCard.
- Соединение абзацев пробелом даёт исходный UTF-8 SHA256 `406d87d0fdb045fc3c262a9cc324b23ca232a655244bf54f72f367d5a0102fe5`.
- Настоящие TextLayoutResult на 320dp при fontScale 1/2 во всех четырёх атмосферах не имеют overflow; контраст текста с карточкой ≥4.5:1, все абзацы доступны вертикальной прокруткой.
- Существующие тесты вкладок/restore и настоящей навигации NavHost/Room/F4/галереи/D2/D3 выполняются без изменения их исходников и assertions.

## Флаг
Не нужен: только утверждённая презентация существующего текста.

## Вне рамок
Фактические правки советов; Журнал, lifetime вкладок, hero/clock/FamilyHand/InkBlot; данные, фото, ViewModel, навигация, схема, backend и общий kit/палитра. Только focused compile/unit; полный gate и одно review — у родителя. Без push, render, APK, устройств и production effects.
