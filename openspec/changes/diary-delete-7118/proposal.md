# D2 · Удаление кормления с пятисекундной отменой

Утверждённый SCREENS-7.0.3 §3:103,106; версия 7.1.18 (71). Только удаление из журнала, без миграции, новой математики, backend или изменения политики фото. Дополнение действующего дневника, без отдельного флага.

- Свайп влево, кнопка в раскрытии и действие TalkBack выбирают тот же снимок строки. Правый свайп/повтор, раскрытие и вертикальная прокрутка сохраняются.
- Единственная ожидающая операция в ViewModel скрывает строку только в журнале. Room, hero, форма и гидратация остаются авторитетными. Полные 5000 мс монотонного времени не зависят от очереди Snackbar, существующая отмена выпечки не меняется.
- «Вернуть» до границы отменяет таймер: остаются исходные id, все поля и JPEG. Дубликат/другая строка не сокращают первое окно. На границе и позднее старый token не восстанавливает строку.
- По истечении срока транзакция повторно проверяет конфиг, владельца и весь снимок; удаляет только его и обновляет только nullable lastFeedingMillis по id DESC. Обычное сохранение сериализуется Room, остальные поля/комментарии/гидратация не переписываются. Файлы не удаляются.
- Рекомпозиция/rotation сохраняют VM-операцию. Выход с видимого дневника (включая форму/альбом) и смена настоящего user/config отменяют ожидание, ABA не оживляет token/старый callback. Таймер не остаётся за экраном, где «Вернуть» недоступно. F4-визит и черновик дочерних экранов не меняются. После смерти VM/процесса нет фонового восстановления таймера; до commit строка остаётся в Room.
- Ошибка транзакции возвращает видимую строку с честным сообщением; повтор доступен.
