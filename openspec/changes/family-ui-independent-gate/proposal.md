# Семья по ссылке: независимый выключенный флаг

## Зачем
Приём приглашения и список семьи уже реализованы в FamilyLinkScreens/ViewModel/API.
Общий FAMILY_ROSTER_V2 включал их вместе с Алисой QA до приёмки семьи.

## Изменение
- FAMILY_LINK_UI=false во всех вариантах; использовать существующие экраны без редизайна.
- Разделить семейные запросы и общий foreground PB auth: QA Алиса сохраняет auth/roster/control.
- Закрыть прямые входы во ViewModel, transport, маршруты и QA fallback к legacy списку.
- «К семье» после подтверждённого join открывает существующий список, не просто закрывает приглашение.
- Сохранить legacy debug/release, локальные данные, removed/pending/rejoin и security assertions.

## Готово
7.1.5 (58), один локальный коммит без push. Сфокусированные compile/unit подтверждают:
выключенные семейные операции не выполняют запросов и не сохраняют приглашение;
отдельно включённая QA account lane работает. Существующие invite/join/readback тесты проходят.
Полный exact suite и независимое review остаются родительскому интегратору до push.
Никаких backend/deploy, QR/login/phone, APK/render или изменений инфраструктуры.
