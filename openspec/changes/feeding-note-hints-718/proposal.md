# Подсказки к заметке о кормлении · 7.1.8 (61)

## Зачем
Реализовать утверждённый SCREENS-7.0.3 §4: облегчить ручную заметку без автоматических наблюдений.

## Что меняется
Под существующим PaperField — горизонтальный ряд PaperChip: «+ пахнет яблоками», «+ крупные пузыри», «+ кислит», «+ жидковата». Только явное нажатие дописывает фразу без «+». Существующий текст, включая пробелы и переносы, остаётся неизменным префиксом; при необходимости добавляется перенос строки. Повторное нажатие — новая вставка.

## Готово, когда
- Четыре точных подписи; до нажатия заметка пуста, без исторических заметок/фото и без автосохранения.
- Каждая вставка и повтор работают; черновик восстанавливается без потери пробелов и переносов.
- Save сохраняет прежние trim/blank-null и validation; реальные фото, ручные/прошлые массы, место, гидратация и повтор после ошибки не меняются.
- Сфокусированные реальные Compose/domain-тесты и debug/release compile проходят через зарегистрированный madre-gradle. Родитель выполняет полный итоговый gate.

## Флаг и границы
Флаг не нужен: завершённое дополнение существующей формы по утверждённому дизайну. Без миграций/новых полей, новых наблюдений, camera/permission-рефакторинга, push, APK и screenshot-прогонов.
