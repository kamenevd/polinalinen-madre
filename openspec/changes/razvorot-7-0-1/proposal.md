# Мадре 7.0.1 — Разворот
## Зачем
Реализовать утверждённый Димой дизайн F как настоящее Android-приложение, сохранив рецепты, данные, выпечку и таймеры.
## Что меняем
- Единственный эталон: `/root/.hermes/work/madre-design/concept-F-v3/F-razvorot-7.0.1/`: SPEC.md, PAGE-CURL.md v3, prototype/index.html и video/F-curl-v3.mp4. Архив SHA-256: `7d483268a975f2242c2e17e6e50c381081f1c3d531191cbe4b303dabd3f409de`. `concept-F/handoff` (v2), прежние F-prototype/F-shots, concept-A и DESIGN-V4.md не применять; v2-файлы не переписывать.
- Приоритеты: P0 из SPEC (§8 A–E), затем P1; веер/наклон/частицы — nice-to-have, не блокируют тестовую поставку.
- Curl v3: захват только в крайних 19% ширины, зоны по высоте 30/40/30; горизонталь задаёт прогресс, вертикаль только поворачивает сгиб до ±15° относительно базового угла зоны, чисто вертикальный жест инертен. Корешок закреплён. Радиус 78→38dp, lag 38мс, порог смаха 0.5dp/мс, пружины 36/68/95 и скорость отпускания. Свет только затемняет, оборот тёмный с бледной зеркальной печатью. Сетка GL/CPU по PAGE-CURL v3, debug-экран «Бумага» и slide-fallback.
- Решение Q2 дизайнера: GLES2 — достаточный минимум при успешной инициализации; GLES3 необязателен, AGSL запрещён. SPEC A8 читать «без GLES2». Нет GL / энергосбережение / меньше движения / низкий fps → плоский сдвиг PAGE-CURL §5.
- Добавить кадры Roborazzi из SPEC §12 и проверку, что CI-кадр 02 (оглавление) отличается от 01; вопросы по дизайну вести в concept-F/QUESTIONS.md для «Дизайнера Мадре», не останавливая код.
- Исторические goldens не меняются. Первые нативные F-v3 кадры `RazvorotV3RenderTest` записываются отдельно в `build/outputs/roborazzi/f-v3/` для приёмки дизайнером, а не выдаются за уже утверждённые pixel-baselines. Instrumented smoke сохраняет прежний обход всех глав, но открывает новое оглавление настоящей навигацией; старые ожидания «РЕЦЕПТ №» заменены проверкой читалки и точного названия текущей главы.
- Обложка, веер/оглавление, непрерывное чтение, выпечка, полноэкранный таймер, закваска, завершение и семейная полка; дневная и ночная темы.
- Бумажное листание: лист следует за пальцем, мягкий загиб, медленное завершение; простой слайд для слабых устройств и режима уменьшения движения.
- Существующие реальные модели состояния остаются источником данных. Демонстрационные подключения, числа и фото не выдаём за реальные.
- Решение Q1 дизайнера: `FeatureFlags.ALICE=false`; в обычном APK нет шторок/кнопок Алисы, заглушек и текста «интеграция выключена». Единственный вход «Подключить Алису» — на Полке в разделе Алисы с пометкой «скоро», без включения интеграции. E1–E4 — только изолированные debug-сцены Roborazzi. PR #58 не изменяем.
- Версия 7.0.1 через scripts/release_cycle.py prepare-version, versionCode +1; строгий SemVer, changelog с временем МСК/заголовком/2–3 пунктами и проверкой согласованности/роста.
- Debug APK для теста устанавливается рядом с production без удаления приложения и его данных.
## Готово, когда
- Экранные состояния и элементы управления воспроизводят утверждённый F в нативном интерфейсе, включая узкий экран и ночь; рецепты и длительности не переписаны ради дизайна.
- Жест следует за пальцем, отмена не теряет страницу, есть слайд-fallback и настройка уменьшения движения; доступные действия не перекрываются.
- Выпечка/таймеры/закваска/полка используют текущие модели; права, публикация фото и согласия сохраняются.
- CI точного итогового коммита зелёный; выполнено одно ревью, доказательства приложены в PR.
- Из этого CI скачаны реальные PNG экранов и debug APK 7.0.1, проверены их метаданные и отправлены Диме в Telegram для установки на Huawei.
